# 模块：masterdata（主数据）

> 所属交付模块：**M1 基础数据与采购**（人类开发者 1）｜分支 `feat/m1-masterdata`
> **负责人（masterdata）**：梁海俊｜接手日期：2026-11-04

## 目标

维护商品、客户、供应商、加工厂四类业务档案，给全部单据提供可选对象；把「编号只是展示字段」这条边界（D49）在实现层钉死。

## 范围与页面

- **功能域（D44）**：商品、客户、供应商、加工厂（加工厂不并入供应商）。
- **页面**：9 商品资料、10 客户、11 供应商、12 加工厂档案。
- **实体**：商品（编号/名称/别名/规格/单位/状态/默认售价）、客户（编号/名称/联系人/电话/账期）、供应商（编号/名称/联系人/供货物料）、加工厂（编号/名称/联系人/历史加工价/比价记录）。
- **不做**：商品成本字段（成本挂批次，D5）；商品/客户/供应商/加工厂编号的固定结构与全局检索主键（D49）；货物位置（二期，D6a）。

## 依赖

- 上游：platform（公司隔离、权限、审计）。
- 下游：inventory（商品）、purchase（供应商）、processing（加工厂）、sales（客户）。

## 开放项

- 无。D49 已明确：编号可空、格式自由、只作展示/对账，定位走「公司内按名称/字段查看」，系统内用 uuid。

## 验收标准

- 四类档案的增删改查 + 停用状态；停用后不出现在单据选对象弹窗。
- 商品维护「默认售价」，E 单开单自动带出（D4.1）。
- 商品支持别名与规格；检索按名称/别名，**不把编号当全局检索键**（D49）。
- 加工厂历史加工价、比价记录可录可查（B 单成本来源）。
- 全部档案按公司隔离，越权读取被服务端拒绝（D15）。
