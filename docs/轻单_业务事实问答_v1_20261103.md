## F2 加工链路（2026-11-03 已答）

| 子题 | 答案 | 对设计的影响 |
|---|---|---|
| 多段委外接力（A厂→B厂→…） | **偶尔有** | B 单支持链式引用（可引用其他 B 单的产出批次作为投入），但非主线场景 |
| 辅料谁买 | **我方采购为主** | 辅料作为成本项进我方成本（D5 已有「辅料」位） |
| 加工厂包工包料（只收加工费） | **有这种情况** | ⚠️ 此情形实质是「采购成品」，应引导走 A 单采购而非 B 单加工；B 单加工费口径 = 纯加工（人工+厂方费用）。若允许 B 单无材料投入会污染批次成本公式，需在契约里约束 |

| 子题 | 答案 | 对设计的影响 |

| 谁填 | **我方人员自填** | 无需「加工厂报数→确认」双录流程 |

## F4 退货的真实流程

### 客户退货方向（2026-11-03 已答）

| 子题 | 答案 | 对设计的影响 |
|---|---|---|
| 谁发起/录入 | **不固定**（销售/老板/经理都可能） | ⚠️ 修正 D4.3：客户退货不能限定「销售发起」，改为**多岗可录、录入需审批**（权限矩阵退货行给销售/经理/老板均可增） |
| 货怎么处理 | **退回仓库 + 存在只退钱不退货**（运损小额补偿等） | 退货单分**两种类型**：退货退款（有入库流水）/ 仅退款（无实物流水，纯金额冲抵） |
| 钱怎么退 | **两种都有**：原路退款、冲抵下一单 | 退款方式字段：原路退款 / 冲抵应收（挂账抵下单货款） |
| C 单已结算后再退货 | **重新算原结算单**，提成跟着调 | 退货关联回原 C 单 → 毛利重算、提成重算（D5④「改比例不重算」仅指比例配置变更，不冲突）；重算需留调整痕迹（日志/调整记录），不覆盖抹除原数字 |

### 供应商退货方向（2026-11-03 已答）

| 子题 | 答案 | 对设计的影响 |
|---|---|---|
| 谁发起 | **不固定**（谁发现谁报） | 与客户退货一致：多岗可录；对外对接仍走采购岗，录入需审批 |
| 采购款怎么冲 | **退钱**（供应商退现金/原路退回） | 供应商退货单金额字段 = 冲减应付/收退款记录；无需「抵下次货款」「换货补发」类型（现实不发生） |

### F4 汇总对「第 6 类冲正单据」字段设计的输入

1. 客户退货单：类型（退货退款/仅退款）+ 退款方式（原路/冲抵应收）+ 关联原 E 单与 C 单 + 触发原 C 单毛利/提成重算（留痕）。
2. 供应商退货单：关联原 A 单 + 退款记录（冲减应付）。
3. 两方向均为多岗可录、需审批。
4. 库存流水：客户退货退回仓库 → 入库流水；仅退款 → 无实物流水。

## F5 库存归属（2026-11-03 已答：两个都要）

| 语义 | 设计落点 |
|---|---|
| **业务归属**（这批货是谁接的单、业绩算谁） | 挂 E 单负责人字段，无需新增（批次可经 E 单追溯到业务员） |
| **实物保管责任**（货实际在谁手上、丢了/盘亏谁负责） | ⚠️ **新增「保管人」字段**（批次/库位级）；盘点差异自动关联保管人，作为差异责任依据；权限上保管人变更需留痕 |

## F7 编号规则（2026-11-03 已定稿）

- 负责人否决了「写死一套格式」与首版提案，要求可定制。
- 行业对照：用友 T+/U8（前缀+日期+流水、按月重置、删单补空号、编号可改）、SAP（编号范围对象，编号=配置项非硬编码）。
- **拍板（负责人确认）：单据编码方案 = 租户级可配置设置 + 出厂默认**：
  - 出厂默认：`A-BJ01-20261103-001`（类型字母 + 公司码 + 日期 + 流水）
  - 类型字母八类：A 采购 / B 加工 / E 销售 / N 内部 / C 结算 / R 客户退货 / S 供应商退货 / I 盘点
  - 可配置项：前缀样式（含拼音缩写）、公司码开关、流水位数（默认 3）、重置周期（默认按月，可选按日/长流水）
  - 全租户唯一性由取号机制（并发安全）保证，进开发契约

## F10 打印/导出版式（2026-11-03 已答）

- 现实中**没有固定版式**（口头/微信/临时表格）。
- 对设计的影响：
  1. 打印/导出一期**没有「还原现有版式」的锚点**，由系统直接设计标准版式：销售单（客户联）、加工单（发厂联）两套模板；
  2. ⚠️ **M 类材料策略改写**：清单原假设「现在靠一张 Excel 汇总成本」（M3）不成立——成本口径验证改为依赖 **M1：一张真实订单的全链路数字**（微信聊天记录截图、口头报数均可，脱敏即可）；M2（真实退货单）同理改为描述一次真实退货经过。
