# 模块：internal-trade（内部交易）

> 所属交付模块：**M4 内部交易与打印**（人类开发者 4）｜分支 `feat/m4-internal-trade`
> **负责人（internal-trade）**：梁海俊｜接手日期：2026-11-04

## 目标

支持同租户内子公司之间调货：N 单在途期间批次归属不变、可用量锁定，签收到货才转司；内部价只记录，不做利润抵消（D45）。

## 范围与页面

- **功能域（D44）**：内部交易单 N。
- **页面**：6 内部交易单 N。
- **实体**：N 单（单号/发出公司/接收公司/商品明细/内部价/在途量/状态/经手人）。
- **不做**：集团看板与内部利润抵消展示（D45 一期完全不做）；跨租户交易（禁止，D14/D15）。

## 依赖

- 上游：platform（权限/取号/状态机）、masterdata（商品）、inventory（批次在途占用、签收转司）。
- 下游：settlement（N 单完成生成 C 单草稿，与 E 同规则 D29）。

## 开放项

- 契约第二批 §4-1：**内部价口径** —— 拟定默认 = 批次成本价，可手工改。开工前拍板并追加 decisions.md。
- 契约第二批 §4-2：**N 单是否产生毛利** —— 拟定不产生（内部调货非对外销售）。开工前拍板并追加 decisions.md。

## 验收标准

- 只引用**发出公司**本公司批次（D22）。
- 在途期间：批次公司字段不变（仍归发出方），该批次可用量按「在途占用」锁定、不得被其他单据引用（D22/D31）。
- 收货方确认到货：解锁在途占用并变更批次归属公司（转司）（D31）。
- N 单单头「已完成」自动生成 C 单草稿，与 E 单同规则；一期一单一次结算（D29）。
- 单号类型字母 N，走 D16 固定编码；状态：进行中 / 在途 / 已完成 / 已取消（契约第二批 §1）。
- 跨公司链路只显示节点不展开内容（D25）。

## 已知问题 / 坑

- 在途锁定的是「可用量」不是「剩余量」：只改剩余量会让别的单据继续引用（D31）。
- 转司要同时改批次公司 + 解锁在途占用，两件事必须在一个事务里。
- 内部价只是记录字段：一期任何报表都不得把它当利润来源（D45）。
- 发货端点落地前，N 单 `inTransitQty` 必须保持 0；不能再用明细数量冒充库存锁定。
