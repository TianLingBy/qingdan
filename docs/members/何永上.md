## 上手步骤（接上仓库后按顺序做）

```powershell
git clone https://github.com/TianLingBy/qingdan.git
cd qingdan
pwsh -NoProfile -File install-hooks.ps1   # 装提交前护栏，并当场跑一遍全量测试
corepack enable
pnpm install
pnpm -r build
pnpm -r test
pnpm -C apps/web dev                      # 前端 http://localhost:5173，/api 代理到 3000
```

装好后读这四样，别一上来就写页面：

1. `README.md`——目录结构与本地跑法；
2. `packages/contracts/src/index.ts` 和 `docs/api/openapi.yaml`——接口真源，页面要调的字段都在里面；
3. `apps/web/src/router/routes.ts`——22 个页面的路由表（现在全部指向占位页 `PlaceholderPage.tsx`，你要逐个替换）；
4. `apps/web/src/api/client.ts`——已有的 HTTP 客户端与错误处理约定，别另起一套 `fetch`。

## 工作流程（团队统一，2026-11-05 起）

1. 任务只在 GitHub issue 领；进度只认 issue / PR 状态，本地笔记不算。
2. 分支：`feat/web-<页面>`（例如 `feat/web-login-page`）。
3. PR 描述必须包含 `- Blocked by: 无` 和 `- Blocks: 无`（没有阻塞也写「无」，否则 CI 的 fields 检查会红）。

5. **提交不直接推 main**，一律 PR；CI 七项（test windows/ubuntu、integration、e2e、spec-drift、route、fields）全绿后由负责人合并。
