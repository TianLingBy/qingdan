- **编号**（D16）：**固定结构、不设开关**，出厂默认 `A-0001-20261103-0001`（类型字母 + 公司码定长 4 位 `0001`~`9999` 全局递增 + 日期 8 位 `YYYYMMDD` + 流水 4 位 `0001`~`9999` 按月重置）；类型字母 A/B/E/N/C/R/S/I；**公司码固定带、不设开关**（公司是数据隔离刚性字段）；**全租户唯一由并发安全取号保证**。
- **权限**（D15/D45）：员工绑定若干「公司 × 岗位」对，权限 = 岗位并集，**数据可见范围 = 绑定的公司集合**；老板 = 租户级（全部公司数据 + 集团主数据），**一期不设集团看板**。
- **归属**（F5）：业务归属挂 E 单负责人；实物责任挂批次**保管人**。
- **计价口径**（D28）：一期系统不管税，售价/成本/运费/加工费录什么算什么，毛利直接按录入数字计算。
- **取消规则**（D21）：未完成且无下游引用的单据可取消，库存流水同事务回滚；支持逆向解锁（先取消下游再取消上游）；已完成/已结算不提供取消，错账一律走冲正 R/S/I。**错账处理路径见 D30（一期不设独立调整单 J，成本侧录错锁定留日志，J 列入二期评估）**。

**状态机（✅ 拍板：单头三态 + 行级过程态）**

```
单头：进行中 → 已完成 / 已取消
明细行：各自持有过程状态（待生产 / 加工中 / 待出库 / 已出库 / 运输中 / 已到货 …）
```

- **取消不是"任一步可取消"**（D21）：**未完成且无下游引用**的单据才可取消，取消时库存流水同事务回滚；支持**逆向解锁**（先取消下游，上游变可取消，每次只查直接下游）；**已完成 / 已结算一律不提供取消**，错账走冲正 R/S/I。

- 旧三套枚举并轨（D4.3）：订单模块「待支付/待出库/加工中/进行中/已完成」与首页原型「待确认/加工中/待交付/已交付/已取消」中的**过程态一律下沉为行状态**；单头只留三态。
- **部分出库**由行状态天然表达，不单独实现（D4.3-3.2）。
- **支付/收款**（D11/D24）：不设独立"支付状态"字段与独立页；在线回调与线下转账人工标记统一进 **E 单详情页「收款记录」块**。
