生产发布必须遵守：

```text

→ pg_restore --list 验证备份可读
→ 执行 0026、0027
→ 执行迁移后自检 SQL
→ 确认 schema-guard 通过
```

历史 `settled_at` 回填只允许使用审计表中的确认记录；不得使用 `updated_at` 兜底伪造确认时间。迁移失败时不得直接修改旧迁移，回滚只能通过新增前滚迁移。
