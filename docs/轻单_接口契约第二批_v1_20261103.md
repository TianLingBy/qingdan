## 0. 范围与边界

**本批覆盖**：内部交易单 N、提成结算、内部定价。
**依赖第一批**：批次、库存流水、C 单（N 单也生成 C 单，D29）。

**关键前提（D45）**：一期不做集团看板、不做内部利润抵消展示；N 单仍保留在一期，支持子公司间调货、在途与签收转司。

---

## 1. N 内部交易单

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| 单号 | text | ✅ | D16（类型 N） |
| 发出公司 | uuid | ✅ | |
| 接收公司 | uuid | ✅ | |
| 商品明细（子表） | — | ✅ | 引用发出公司批次 |
| 内部价 | decimal | ✅ | 见 §3 内部定价 |
| 在途量 | decimal | ✅ | 调货数量 |
| 状态 | enum | ✅ | 进行中 / 在途 / 已完成 / 已取消 |
| 经手人 | uuid | ✅ | |

**核心规则（D22/D29/D31）**：
- N 单调货在途期间，批次公司字段不变（仍归发出方），收货方确认到货才变更转司。
- 在途期间批次可用量按在途占用锁定，不得再被其他单据引用；到货确认后解锁。
- N 单与 E 单同规则：单头「已完成」自动生成 C 单草稿，财务确认生效；一期一单一次结算（D29）。
- 只引用本公司批次（发出方视角，D22）。

---

## 2. 提成

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| 归属 C 单 | uuid | ✅ | |
| 归属人（岗位/人） | uuid | ✅ | E→N 提成归 E 单负责人（D5④） |
| 提成比例 | decimal | ✅ | 按人/岗设 |
| 比例快照 | decimal | ✅ | **结算时快照（D36）** |
| 提成金额 | decimal | ✅ | 一期仅为报表数字（D11） |

**核心规则（D5④/D36/D40）**：
- 比例按人/岗设、改比例不重算历史单、负毛利记 0、E→N 归 E 单负责人。
- 提成以 C 单为单位结算、不跨单归并。
- 错账重开：R 单必须全额冲回原 E 单成交总额，原单提成归零（D36）。
- 减成交额退款：按快照比例重算提成并留痕；纠收款退款不重算（D40）。
- 一期不做记账、不代发工资（D11）。

---

## 3. 内部定价

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| 内部价 | decimal | ✅ | 子公司间调货定价 |

**🟡 开放项**：
- 内部价口径：成本价 / 成本加成 / 双方协商价 —— **交由同事开发阶段定（见 §4）**。
- 一期不做内部利润抵消展示（D45），但 N 单仍需记录内部价供后续二期抵消计算。

## 4. 🟡 开放项（开发阶段定，非阻塞冻结）

> 以下 5 项已确认「不阻塞冻结」，**交由同事在开发阶段决定**。开发到相关模块时须先拍板。

|---|---|---|---|
