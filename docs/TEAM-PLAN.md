## 四、怎么收到任务和通知

1. **任务领取与进度以 GitHub Issues 为准**（公告 #69）；不再用本地记录或聊天记录当进度依据。
2. 被 **assign** 的 issue 会给你的邮箱发通知；评论里 **@** 你也会通知。没有被 assign / @，就不会收到任何提醒——所以请每天主动看一次。
3. 每天开工先看：<https://github.com/TianLingBy/qingdan/issues>
4. 分工变动由负责人更新本文件；发现与自己理解不一致，直接在对应 issue 里 @ 负责人，不要私下拖着。
