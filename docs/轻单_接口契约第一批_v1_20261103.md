## 0. 范围与冻结边界

**本批覆盖（第一批冻结范围，D3）**：
- 单据：采购单 A、加工单 B、销售单 E、结算单 C
- 实体：批次、库存流水、商品明细、费用明细、收款记录、损失记录
- 规则：成本随批次锁定（D5）、取消级联（D21）、改价下限（D20）、费用行正负（D39）、退款记账（D34/D40）、库存可用量（D38/D41）、成本更正（D37/D42）

**本批不覆盖（第二批，D3）**：
- 内部交易单 N、提成结算、内部定价

**冻结 = 字段名 + 类型 + 必填 + 规则 + 状态枚举不再变**；界面文案、性能、部署细节不在契约冻结范围。

## 1. 通用约定（跨所有单据）

### 1.1 编号（D16）
- **固定结构、不设开关**，出厂默认 `A-0001-20261103-0001`：类型字母 + 公司码（定长 4 位）+ 日期（8 位 `YYYYMMDD`）+ 流水（4 位，按月重置）。
- 类型字母：A 采购 / B 加工 / E 销售 / N 内部 / C 结算 / R 客户退货 / S 供应商退货 / I 盘点。
- 公司码定长 4 位（`0001`~`9999`，租户内全局顺序递增，公司名/城市作独立字段）；流水 4 位（`0001`~`9999`，按月重置）；公司码固定带、不设开关；全租户唯一由并发安全取号保证。

### 1.2 权限（D15/D44）
- 员工绑定「公司 × 岗位」对，权限 = 岗位并集；数据可见范围 = 绑定公司集合。
- 老板 = 租户级；一期不设集团看板（D45）。
- 动作枚举（底层 8）：查 / 建 / 编 / 审 / 出库 / 删 / 看价 / 导出。

### 1.3 计价口径（D28）
- 一期系统不管税；售价/成本/运费/加工费录什么算什么，毛利按录入数字直接算。

### 1.4 归属（F5）
- 业务归属挂 E 单负责人；实物责任挂批次「保管人」字段。

### 1.5 状态机（D4）
- 单头三态：`进行中 / 已完成 / 已取消`。
- 明细行过程态：`待生产 / 加工中 / 待出库 / 已出库 / 运输中 / 已到货`（按单据类型取子集）。

## 3. 单据核心（第一批）

### 3.1 A 采购单

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| 单号 | text | ✅ | 编码 D16 |
| 供应商 id | uuid | ✅ | |
| 商品明细（子表） | — | ✅ | 见 §5 |
| 费用明细（子表） | — | 选填 | 运费/杂费；**金额可负（供应商返利等），负数须填备注（D39）** |
| 状态（单头） | enum | ✅ | 进行中 / 已完成 / 已取消 |
| 经手人 | uuid | ✅ | |

**核心规则（D5/D21/D37/D42）**：
- 入库即锁批次价：`批次单价 = (货款 + 运费 + 杂费) ÷ 入库数量`。
- 已完成/已结算不提供取消（D21）。
- 成本更正按下游引用状态分 T1/T2/T3（D37）：
  - T1 未被任何下游引用 → 可改批次价并重算，须审批。
  - T2 已引用但下游 B/E 未完成 → 取消下游 → 改价 → 重开下游，须审批。
  - T3 已结算/跨期 → 锁定不改，留日志 + 备注 + 净毛利页免责说明。
- 审批人：老板/经理/财务（D42）。

### 3.2 B 加工单

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| 单号 | text | ✅ | D16 |
| 引用批次（材料投入） | uuid[] | ✅ | **至少一条材料投入（F2b）**；可链式引用其他 B 单批次（非主线） |
| 辅料 | text | 选填 | 默认我方采购，进成本 |
| 加工厂 id | uuid | ✅ | |
| 加工费 / 运杂费 | decimal | ✅ | **费用行 ≥ 0（D39）** |
| 损耗量 | decimal | ✅ | 我方人员验收时一次填入，事后不改（F3） |
| 可售量 | decimal | ✅ | = 投入量 − 损耗量 |
| 归属单 | text | 选填 | E 或 N；全损耗时提示挂单，用于 D35 损失归属 |
| 状态 | enum | ✅ | 进行中 / 已完成 / 已取消 |

**核心规则**：
- 产出新批次：`批次单价 = (引用材料成本 + 辅料 + 加工费 + 运杂费) ÷ 可售量`。
- 只摊量不减价（D5）。
- 可售量 = 0（全损耗）→ 二次确认，不生成产出批次，材料+加工费全额记损失（G2/D26）。
- 只能引用本公司批次（D22）。
- 包工包料（只收加工费）不得走 B 单，走 A 单（F2b）。

### 3.3 E 销售单

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| 单号 | text | ✅ | D16 |
| 客户 id | uuid | ✅ | |
| 商品明细（子表） | — | ✅ | 见 §5；售价随单据（不随批次） |
| 费用明细（子表） | — | 选填 | **费用行一律 ≥ 0（D39）** |
| 状态 | enum | ✅ | 进行中 / 已完成 / 已取消 |
| 经手人 | uuid | ✅ | |
| 收款记录（内嵌块） | — | ✅ | D24，见 §6 |

**核心规则**：
- 只能引用本公司批次（D22）。
- 改价下限 = 行级加权平均批次成本；破下限需审批（老板/经理），按行触发、审批中行锁定（D20）。
- 费用行跳过下限校验，但 E 单费用行禁止负数（D39，防绕过破下限审批）。
- 折扣/返利走售价字段或收款记录冲减或冲正单据。

### 3.4 C 结算单

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| 单号 | text | ✅ | D16 |
| 来源单（E 或 N） | uuid | ✅ | E/N 单头「已完成」自动生成草稿，财务确认生效（D19/D29） |
| 总售价 | decimal | ✅ | 计算值 |
| 总成本 | decimal | ✅ | 计算值 |
| 毛利 | decimal | ✅ | = 总售价 − 总成本（D5） |
| 毛利率 | decimal | ✅ | = 毛利 ÷ 总售价 |
| 本单相关损失 | decimal | ✅ | 见 D35/D43 |
| 净毛利 | decimal | ✅ | = 毛利 − 本单相关损失（D33） |
| 提成比例快照 | decimal | ✅ | **结算时快照（D36）** |
| 提成金额 | decimal | ✅ | 一期仅为报表数字（D11） |
| 状态 | enum | ✅ | 待确认 / 已结算（草稿→确认） |

**核心规则**：
- 一期一单一次结算，不支持部分/多次（D19）。
- 结算后不可冲正，走退货（D2③）。
- 本单相关损失 = Σ(归属单 = 本单对应 E/N 单 的 B 单损失金额)（D35）。
- 提成以 C 单为单位结算、不跨单归并（D36）。

| 商品 id | uuid | ✅ | |
| 锁定单价 | decimal | ✅ | A 单入库或 B 单产出时锁定（D5） |
| 入库量 | decimal | ✅ | |
| 已引用量 | decimal | ✅ | 出库累计 |
| 剩余量 | decimal | ✅ | = 入库量 − 已引用量 |
