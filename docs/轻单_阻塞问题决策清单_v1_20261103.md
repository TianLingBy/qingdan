## 2. 决策项

### D1【拍】产品性质与部署（v1 §9.1-1/2，卡一切）

**一句话二选一**：A. 集团内部使用（子公司 = 集团下属）；B. 对外销售的产品（多租户/意向客户成立）。

- 材料证据（竞品定价、目标定价、首批意向客户、企业注册、邀请码）指向 B；「供集团内部使用」指向 A。两者必有一个不是现状。
- 拍板后解锁：权限矩阵要不要公司/租户维度；「老板」是集团老板还是公司老板；企业注册/邀请码做不做；日志「本地+云端双份」怎么落地；`project-context.md` §9 那句「不做多租户 SaaS」改还是留。

> **✅ 拍板（2026-11-03 会话讨论，拍板人：天零；若非项目负责人本人，需拿去追认）**：**一步到位做对外 SaaS**（选项 B）。
> 连带后果（进入待办）：
> ① 数据模型全表带企业（租户）维度；权限矩阵增加公司维度（原 D4.5 从「依赖 D1 待定」变为「必做」）。
> ② 企业注册 / 邀请码 / 员工加入进一期。✅ **S3 已拍（2026-11-03 会话讨论）**：老板预建 + 邀请码 + 手机号白名单三合一——老板注册企业后可生成邀请码，也可预先录入员工手机号，员工注册时校验手机号自动入企。遗留小项：员工手机号已被其他企业占用时的归属冲突规则，待确认。
> ③ ✅ **集团挂法已拍（2026-11-03 会话讨论）**：「老板」= 入驻企业老板；集团多子公司 = **一个租户内多公司**（入驻主体=集团，子公司数据隔离、总部可看全部），N 单与集团看板在同租户内成立。
> ④ ✅ **部署与日志收口（2026-11-03 会话讨论第二轮）**：一期 = **云端 SaaS 订阅版单一形态**（软件与运行数据在我们云端，云端为唯一记账真相）；客户本地保留**只读备份副本**（自动推送/定期核对，断网只可看不可改，修改一律联网）；**买断版（软件部署到客户云服务器）推二期**，一期内买断诉求用「永久授权 + 数据可完整导出」实现。规则 #8 日志双份收口：云端存储 + 本地备份副本。
> ⑤ `project-context.md` §9「不做多租户 SaaS」句必须修订（待落文档）。
> ⑥ ✅ **计费已拍（2026-11-03 会话讨论）**：一期不做在线支付/自助订阅；做**开发人员管理后台的手动计费配置**（对任意企业设置套餐与到期）。遗留小项：到期未续费的处理方式（停用/只读），待确认。

### D2【拍】单据分类学（v1 §9.1-5）

**建议**：以 **A(采购)/B(加工)/E(销售)/N(内部交易)/C(结算)** 为骨架；仓库那 6 种（采购单/生产单/退货申请/出货单/调货单/日常备货）**降级为「业务动作」或「库存流水类型」**，不与五类并列。

- 对应关系（待负责人确认）：采购单→A 单的产生动作；生产单→B 单；出货单→E 单的出库环节；退货申请→独立退货单据（见 D4.3）；调货单/日常备货→库存动作（一期是否做需单说）。
- 拍板后解锁：13 页重排（D3）、各类单据状态机统一（D4.3）。

> **🟡 进展（2026-11-03 会话讨论）**：负责人说明保留多种单据的动机是「方便核算成本、追溯成本」。本清单已送达评估（11 种并行的隐患：同义双记成本算两遍、追溯断在两套编号、11 套状态机、页面膨胀）+ 五类骨架运作示例（A 锁批次价 → B 引用加工 → E 售价随单 → C 唯一算毛利；追溯靠流水四要素：数量/批次/来源单据/经手人）+ 全面可行性审查（结论：架构为行业验证模式，无致命项；6 条新契约规则：①单据与流水同事务 ②提交时校验批次余量 ③C 单结算后不可冲正走退货 ④库存页显示委外在途量 ⑤动作生成回执号 ⑥盘点=动作+盘盈盘亏冲正流水）。**✅ 盘点拍板：进一期**（审查新发现的盲区，1030/1103 两份清单均漏列）。**✅ 最终拍板（2026-11-03 会话讨论）：五类骨架通过**（含 6 条契约规则与盘点机制）。

### D3【拍】13 页地基与重排（结构性，最优先的产品定位题）

**现状**：13 页是照「权限表 11 个业务域」长出来的，缺加工单 B、内部交易 N、结算 C、加工厂档案、批次与成本锁定、库存流水、毛利/提成视图。权限表能说「谁能点什么」，说不了「价值链是什么」。

**三选一**：

| 选项 | 内容 | 代价 |
|---|---|---|
| (a) | 先补「五类单据 + 成本归集」骨架，再回看 13 页归属 | 与 v1 口径完全一致，成本最高 |
| (b) | 一期只做「订单+库存+权限」最小闭环，A/B/E/N/C 与成本核算推二期 | 产品从「一单一成本一单一毛利」退化成进销存，**与 v1 §1 直接冲突**；且加工厂档案、批次、库存流水即便选它也躲不掉（v1 §9.1-7、仓库白板有批次号），实际省不了多少 |
| (c) | 一期做 A→B→E 主链 + C 单只算成本毛利（不做提成、不做 N 单） | 〔倾向 (c)〕卖点可演示（有 C 单才有毛利可看），把依赖口径未闭合的提成与内部交易推后 |

**注意**：即便选 (c)，13 页也不是推倒重来——主数据/库存/组织 9 页全部保留归位，真正新增的是单据链（A/B/E/C）+ 批次 + 加工厂档案 + 毛利视图。重排 ≠ 重画。

> **✅ 拍板（2026-11-03 会话讨论，拍板人：天零）**：选 **(a) 全量五类**（A/B/E/N/C + 提成 + 内部交易全进一期）。
> 随拍板生效的风险缓解：**契约分两批冻结**——第一批 A/B/E/C 主链 + 批次 + 库存流水（依赖成本口径 4 条）；第二批 N 单 + 提成 + 内部定价（依赖转单归属、负毛利、转移定价）。开发顺序 A→B→E→C 先行，N/提成随后；两批互不阻塞，第二批口径未谈拢不影响第一批开工。

### D4 权限与状态机

- **D4.1【拍】「管理」语义**：查+编辑+审批，还是仅「授权他人」？
  业务反证：若仅授权，经理不能编辑商品成本，而矩阵里采购=编辑成本——那成本的最终确认人是谁？这条同时定义「老板」与「经理」的差别。〔倾向：管理=查+编辑+审批，否则经理在业务链上无处落地〕
  🟡 **推荐方案已给出（2026-11-03 会话讨论，待负责人修改定稿）**：「全部」=查看+编辑+审批+授权他人（老板专属，不可被收回）；「管理」=同四项（经理用，老板可收回）；每行特殊值覆盖默认。7 个待确认行推荐值：3 行质检 否→查；5 行理货 编辑→查；6 行保持（采购不能自审）；7 行保持但拆客户退货/供应商退货两方向；8 行删（D6a）；10 行销售 查看需审批→查；11 行随页进二期。连带新规则（待确认）：价格列可见性与页面可进分开授权（价格由「商品成本」行管）。
  🟡 **方向改定（2026-11-03 会话讨论，负责人提出，取代上面推荐表的核心争议）**：权限模型升级为「**预设岗位 + 自定义岗位**」——出厂预设岗位（老板=全部权限；经理=查改增删+下发权限；财务=查看成本流水；仓管、业务员各按矩阵默认值），**老板可在预设岗位上增减权限，或新建自定义岗位**。原 8 列矩阵降级为出厂默认值，不再是硬编码结构；「管理」语义之争由**动作级授权**取代（功能域 × 动作勾选）。连带：**S1（权限由谁配置）拍板 = 老板自定义（预设兜底）** ✅。待定稿两件：① 动作枚举（建议：查/增/改/删/审批/授权/导出/看价格）；② 原矩阵特殊值（录入需审批、仅删减等）映射为出厂预设勾选；③ 功能域清单按 D3=(a) 扩展（新增：加工单、结算/毛利、库存流水、加工厂档案、提成、内部交易、公司管理）。
  ✅ **配置体验方案已同意（2026-11-03 会话讨论）**：8 动作保留为底层模型；配置界面分两档——**简单模式**（老板默认）：每功能模块三档「不看/只看/能操作」+ 单独的「能看价格」勾选框；**高级模式**（点开）：8 动作细粒度，简单模式下默认映射为审批随「能操作」、导出随「只看」、授权仅经理/老板预设；新建岗位默认「复制现有岗位」再改。
- **D4.2【拍】岗位清单**：矩阵 8 岗（无仓管员）／仓库白板 5 岗（含仓管员）／规则 #9「仓管员 ⊇ 拣货工，小企业可不设拣货工」。
  〔倾向：理货/拣货/仓管员并为「仓管」一岗，矩阵 8 列变 7 列；需同时回答「一人多岗」怎么表达〕
  🟡 **2026-11-03 会话新增关键输入**：中小企业普遍**一人多岗**（无专职采购/质检）。推荐机制（待拍）：矩阵列 = **岗位模板**，员工账号可勾选多岗、权限取并集；「仓管员」不新增列，做成**预设权限包**（一键勾 = 理货+拣货+质检查看格，满足规则 #9）。兼任采购+经理可自审采购单，系统不禁止、日志留痕（规则 #8 兜底）。
  ✅ **拍板（2026-11-03 会话讨论）**：**预设岗位 + 老板可增减权限/新建自定义岗位**；一人多岗、权限取并集；「仓管员」= 预设权限包。岗位清单三份不一致问题收口（完整问题清单 P1-10 ✅）。

### D5【拍】成本与毛利口径（4 条 + 1 份材料）

| # | 口径问题 | 现状与提示 |
|---|---|---|
| 1 | 成本单价随批次锁定还是随单据浮动 | 规则 #14「商品编号 = 采购批次 = 成本唯一标识」已强暗示**随批次锁定**，〔倾向确认锁定〕——这条最接近已定 |
| 2 | 损耗折算用哪个价（原料价/成品价/均价） | 无任何依据，必须业务口述；B 单算例单价 25 隐含「投入−损耗=可售量」规则，白板无一字说明，须确认这是不是本意 |
| 3 | 费用项（运费/加工费/杂费/损耗）与商品明细分表还是同表 | v1 §11.2 已指出混表导致售价合计与成本合计口径不对称 |
| 4 | 提成比例谁设、按人还是按单、负毛利记 0 还是挂账 | 算例假定 10%、记 0，均非规则（v1 §6.3） |
| 材料 | **要一单真实成交数据**：A/B/E 各多少、成本怎么摊、最后毛利多少 | 没有它，算例 4 处不闭合补不平，公式无法验证 |

> 🟡 **推荐口径已给出（2026-11-03 会话讨论，待负责人逐条确认）**：
> ① ✅ **拍板：成本随批次锁定**——批次单价 =（货款+运费+杂费）÷ 入库数量；B 单产出新批次，单价 =（引用材料成本+辅料+加工费+运杂费）÷ 可售量。
> ② ✅ **拍板：损耗只摊量不减价**——材料成本全额进产出批次，可售量 = 投入量 − 损耗量（白板 B 单「单价 25」隐含规则的正式化）。
