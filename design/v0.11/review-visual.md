# 美感审查 · v0.10 → 已修到 v0.11
> 说明：claude CLI 通道未配置 dsh 模型端点，无法启动，本文件由主代理自查。

## 结论
v0.10 的质感已经回到 v0.8 水准：暗色苔绿 + 卡片高光 + 渐变数字。剩下的问题集中在「密度」和「节奏」：信息块之间的留白不均，表格和卡片是两套阴影语言。

## 主要问题
1. **两套阴影语言**：`.card` 用 `--sh-1 + 内高光`，`.kpi` 用渐变 + 顶部细线，同屏出现像两个系统 → v0.11 统一为「渐变底 + 1px 内高光 + 同一档投影」。
2. **字号阶梯太密**：22 / 14 / 13.5 / 12.8 / 12 / 11.5 六档挤在一起，层级靠颜色而非大小 → v0.11 收敛为 25 / 14 / 13.5 / 12.5 四档。
3. **留白不均**：页头与筛选条 20px、筛选与表格 12px、表格与说明 12px，视觉上一紧一松 → 统一为 8 的倍数。
4. **强调色过载**：状态胶囊、KPI 数字、按钮、图标都在抢苔绿 → 强调色只留给「主操作 + 当前项 + 关键金额」。
5. **侧栏图标是同一个方框**：22 项长得一样，扫读靠文字 → 建议按域给 8 个图标（v0.11 未做，列为下一步）。

## 已落地
- hero 压缩、卡片与指标卡统一材质、表格行 hover 左侧强调条、分页文案弱化、空态插画位
- 亮色模式单独校了一次对比度：`--text-3` 提到 #5F6B65（暗色 #98A5A0）

## 下一步建议
按域补 8 个侧栏图标；报表页把数字表和折线图合到一屏；主数据四页补批量选择。
