# 轻单 v0.10 · 视觉回收版

> 结构继承 v0.9（22 页 IA、8 域侧栏、新交互），视觉密度回到 v0.7 / v0.8。

## 改了什么

1. **视觉层 `visual.css`**：页面底纹、卡片渐变与内高光、KPI 数字渐变、表头渐变、行 hover 左侧强调条、状态标签底色、按钮渐变与投影、入场 rise 动效。v0.9 用的是通用 `page.css`，扁平；v0.10 在这之上加一层。
2. **工作台重画**：hero 问候卡（渐变 + 光斑 + 标签）、三块 KPI、左「等我处理」列表（类型色块 + 金额 + 状态）+ 右「今天发生」时间线、20 个入口卡（编号 + hover 抬升）。
3. **登录页重画**：星空底（多层 radial + 闪烁）、中心光晕、**毛玻璃卡片**（blur 22px + 内高光）、「获取验证码」60 秒倒计时。
4. 其余 22 页通过 `visual.css` 自动获得同一套卡片/表格/按钮质感，无需改结构。

## 文件

- `visual.css` — 视觉回收层（在 page.css 之后加载）
- `工作台.html` / `登录页.html` — 重画
- 其余页面与 `nav.js` / `ui.js` / `ui.css` / `fonts.css` / `tokens.css` / `components.css` 继承 v0.9
