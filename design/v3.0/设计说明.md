## 四态怎么实现（要上传仓库，按契约来）

**这一版不是 JS 条件渲染**：同一块 DOM，四个分支常驻，切换时 `applyState()` 里一行 `innerHTML` 都没有。

| 层 | DOM 结构 | 谁在管 |
|---|---|---|
| **列表页**（单据 6 页 / 主数据 4 页 / 员工 / 库存 3 页 / 操作日志 / API / 公司） | `<div class="card list-card" data-state>` → `<tbody data-state>` → 数据行 `tr.r-row` + 三行状态 `tr.st-tr.st-empty / .st-loading / .st-error`（每行 `<td colspan=列数>`） | CSS：`tbody[data-state="empty"] > tr.r-row{display:none}` + `tbody[data-state="empty"] > tr.st-tr.st-empty{display:table-row}`；**表头保持显示，列宽不塌** |
| **面板页**（工作台 / 流程图 / 冲正 / 权限矩阵 / 报表 / 设置中心） | `#dyn[data-state]` → `.st-block.st-filled`（真实内容）+ `.st-block.st-empty` + `.st-block.st-loading` + `.st-block.st-error` | CSS：`[data-state] > .st-block{display:none}` + 对应分支 `display:block` |

取值与仓库同名：`filled / empty / loading / error`（`apps/web/src/lib/list-state.ts:16`）。切换只走 `applyState()`：

```js
function applyState() {                 // 等价于 React 里 setState 后由 CSS 接管
  $('#dyn').dataset.state = stateOf();  // 面板层的容器属性
  $$('#dyn [data-rows]').forEach(el => { el.dataset.state = cardState(el); });  // 列表层的 card / tbody
}
```

落地映射：`迭代\issue简报-r2-批次缺口.md` 的「架构口径」一条已按此关闭；给 repo 的对接稿见 `UI重构\新UI\四态与组件对照-给repo.md`（里面有可直接抄的 tsx 片段、类名清单、每页属于哪一层）。

## 设置中心的星空（2026-11-26 追加，含实现口径）

设计稿里这一版设置中心右侧/背景有一套**流星雨**：不是卡片，是铺满整页的背景装饰层（`.meteor-bg`，`position: fixed`、`pointer-events: none`、无边框无底色），页面内容压在它上面。

- **只在暗色出现**：亮色模式下流星雨与按钮都不出现（切回暗色即恢复）。
- **三种节奏**：平时零星（每 150–650ms 一颗、方向随机）；小流星雨（每 18–40s，6–10 颗）；大流星雨（每 75–135s，12–20 颗）。
- **大流星雨两种落法各半**：
  - 同方向斜落的小分队：3–5 颗一组、同一斜角（26°–58°）、**起点横向与纵深都错开**（不在同一起跑线）、到达时间前后错开 70–220ms；
  - 辐射点模型：所有成员反向延长线过同一点（辐射点，屏幕顶部一带），**越靠近辐射点拖尾越短、越远越长**（透视），到达时间按泊松间隔铺在约 7 秒里。
  - 依据：真实流星雨成员看起来都从同一个辐射点散开（BIRA-IASB 流星雨说明），英仙座 ZHR≈100/h、双子座 120/h，亮度分布指数 ≈2.1–2.6（多数暗、少数亮）。
- **右上角棱形星星按钮**：29px、静止不透明度 0.38（悬停才明显）；悬停星星顺时针转 90°，点击放大发亮约 0.64s 并撒一拨流星，随后**设置面板淡出、只留流星雨**（底部提示「只看星空 · 点击星星回到页面」），再点恢复；切亮色或离开页面自动复位。
- **读取方式**：`index.html#settings` → 右上角切暗色。

实现落点（产品仓）：`apps/web/src/components/MeteorBackdrop.tsx`（画布）、`meteor-falls.ts`（落法编排，可单测）、`SkyBackground.tsx`（按钮 + 只看星空），样式在 `app-v30.css §6`。
