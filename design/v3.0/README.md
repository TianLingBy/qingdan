# 新 UI · v3.0

> 一个**单文件、零构建、零外链**的工作原型：22 页 + 登录页 + 入企页 + 打印客户联，亮暗双模、四态、角色权限联动都在里面。定位是 `#431`～`#435` 五张「套 v0.13」批次单的**新 UI（v3.0）**实现参考。
>
> **与 `design/v0.13/` 的关系**：`design/v0.13/` 是赖皓妍的 22 页视觉稿（repo 实现的对齐目标），本目录**不替换它**，是同一批需求的另一条视觉路线（米白 + 朱砂）与可直接跑的四态实现。取舍以负责人拍板为准。

## 打开

- 双击 `index.html` → 管理工作台
- `index.html?view=login` → 登录页（手机号 + 验证码，演示环境任意 11 位 / 6 位可进）
- `index.html?view=login-error` → 登录失败态（`data-state="error"`）
- `index.html?view=enter` → 入企页（邀请码三态：`QD2026` 成功 / `INVALID` 码无效 / `JOINED` 已加入）
- `Ctrl/⌘ + K` → 命令面板；点单据行 → 详情抽屉（含「行明细」与「打印客户联」）

## 四态是 CSS 驱动（可直接照抄进 apps/web）

**同一块 DOM、四个分支常驻、切换只改属性**，与 `apps/web/src/styles/README.md` §四态、`app-v013.css:38-53` 的契约一致，取值 `filled / empty / loading / error`：

| 层 | 结构 |
|---|---|
| 列表页 | `tbody[data-state]` + 数据行 `tr.r-row` + 三行 `tr.st-tr.st-empty/.st-loading/.st-error`（表头保持、列宽不塌） |
| 面板页 | 容器 `[data-state]` + `.st-block.st-filled/.st-empty/.st-loading/.st-error` |

实现细节、每页归属、图标 path、与 `#425`「不许画」的逐条对照，都在 **[四态与组件对照-给repo.md](./四态与组件对照-给repo.md)**；和后端逐条对齐的清单（cap 真名、改掉的假功能、唯一要后端补的一处）在 **[后端对齐清单.md](./后端对齐清单.md)**；三批改动的演进与每批验证结果在 **[设计说明.md](./设计说明.md)**。

## 覆盖了哪些批次要求

- `#431`：单据 5 页 + 冲正三栏 · 筛选条/表格/**分页**/空态 · 单据头 · **行明细表** · 动作区三态 `title` · 「看谁的」开关
- `#432`：主数据 4 页 + 员工 · 详情抽屉（字段分组 + **对接人列表**：主对接人/手机号脱敏/软停用 + 加工厂**报价** + 历史单据）
- `#433`：库存数量（**库龄** / **低库存预警** / 可用量构成）· 库存流水（**类型** / **金额**）· 盘点（**盘盈单 / 盘亏单 / 批准 / 驳回（必填原因）**——后端没有编辑与删除端点，已按契约改掉）
- `#434`：**权限矩阵 24 域 × 11 动作**（首行首列冻结、允许/拒绝/继承三态；域与动作取自 `domains.ts`）· API 密钥（**一次性显示** + 吊销；无「重发」端点，改为新建）· 报表周期筛选 · 日志筛选条（无导出端点）
- `#435`：登录三态（提交 loading / 错误态 `data-state`）· **入企页** · 工作台
