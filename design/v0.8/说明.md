## 〇、先看这个：颜色怎么换

| 方式 | 操作 |
|---|---|
| 临时切换 | 内页**侧栏底部**、登录页**右下角**的配色切换器，4 个色点，点击即时生效并写入 `localStorage` |

## 一、v0.7 改了什么

### 1. 色阶重做：从「平」到「有层次」

v0.6 四阶底色亮度差只有 3–4%，卡片几乎贴在背景上，只靠 1px 的 6–10% 描边分辨。
v0.7 把层差拉到 **8–12%** 并引入 elevation：

| 层 | v0.6 | v0.7 moss | 用途 |
|---|---|---|---|
| 页面底 | `#0F1114` | `#0A0E0C` | 视口 |
| 侧栏 | `#13161B` | `#101613` | 导航 |
| 卡片 | `#181C22` | `#1A211C` | KPI / 面板 / 表格容器 |
| 控件 | `#1F242B` | `#252E28` | 输入框 / 悬浮层 |
| 更高层 | `#272D36` | `#323C35` | hover / 弹层 |

同时 `--line-1` 从 `.06` 提到 **`.12`**，卡片加 `--elev-1`（描边 + 柔和投影），表格加隔行 2% 底色 —— 截图里「行糊成一片」的问题解决。

### 2. 语义化命名（还掉 v0.6 的债）

`--gold / --gold-lt / --gold-dk / --sh-gold` 里存的其实是钢蓝 `#8FA9BE`，注释写着「琥珀金」，页脚还是 `v0.5`。v0.7 全部改成语义名：

```
--gold*   → --accent / --accent-light / --accent-deep
--blue*   → --accent-2 / --accent-2-light
--w-1..4  → --text-1..3 / --text-decor
--g06..   → --a-06.. / --b-16..
--sh-gold → --sh-accent
```

**页面里所有颜色字面量已消除**：`rgba(143,169,190,.5)` → `rgba(var(--accent-rgb), .5)`，
`rgba(230,232,234,.06)` → `rgba(var(--text-rgb), .06)`，
`rgba(15,17,20,.88)` → `var(--topbar-bg)`。
四套主题各自定义 `--accent-rgb / --text-rgb / --accent-2-rgb`，所以换色真的只改一个文件，不再需要 `palette.mjs` 整体编译。
旧变量名保留为兼容别名（定义在 `tokens.css` 末尾），即使有遗漏也不会出现裸色。

### 3. 抽出 `components.css`

v0.6 的 sidebar / topbar / crumb / btn / card 样式在 4 个内页各复制一份，且**已经漂移**：
`.sb-mark` 工作台有投影、单据没有；`.sb-link svg` 工作台有 transition、单据没有；同名 `.btn` 工作台 40px、单据 30px。

v0.7 把 SIDEBAR 段从 4 个页面整段移除，改为 `components.css` 唯一来源；其余公共组件由 `components.css` 统一覆盖（后置加载）。页面只保留自己的布局。
按钮统一到 36px 基准 + `.page-head .btn-primary` 40px + 登录卡 46px 两个显式变体。

### 4. P0 硬伤（评审方案里的红点）

| # | 问题 | v0.7 |
|---|---|---|
| 1 | `--w-4`(2.98:1) 被 20+ 处信息性文本误用 | 拆成 `--text-3`（.62 ≈ 6.3:1，AA）与 `--text-decor`（.42，仅眉标/分隔符）；页面旧写法统一迁到 `--text-3`，装饰用途由 `components.css` 覆盖回去 |
| 2 | 登录页缺 `:focus-visible` | `tokens.css` 提供全站焦点环 `--focus-ring` |
| 3 | 单据 `thead top:0` 与 sticky topbar 打架 | `thead th{top:var(--topbar-h)}`（52px） |
| 4 | `.cb` 15px / `.opt .c` 16px / `.st-btn` 30px 高 | 视觉尺寸不变，用伪元素把点击热区补到 **32×32**（超过 WCAG 2.2 AA 的 24px 要求，且不侵入相邻列）；按钮类控件 `min-height:44px` |
| 5 | 断点四套（980/900/1080/720） | 统一 **1024 / 768 / 480** |
| 6 | 登录卡 `panelIn` 动画用 `both` 填充，动画未推进时整张卡停在 `opacity:0` | 去掉 `both` 与 100ms 延迟，元素默认态即可见，动画只负责淡入 |
| — | JS 动态 SVG 用 `setAttribute('fill','var(...)')` 无效 | 改用 `style.fill / style.stroke`，主题变量真正生效 |

### 5. P2 视觉优化

- **强调色收敛**：KPI 标签、中文表头、筛选组标题、单据号胶囊、报表指标标签一律降为中性 `--text-2/3`；强调色只留给每屏 **1 个实心主操作**、激活态、关键金额和图表主线。中文表头改回 `sans`（mono + uppercase 对中文无效且基线不齐），只有数字列用 mono。
- **字号下限**：信息性文字 ≥ 12px（原先 9–11.5px 全站 60+ 处）；装饰性英文眉标 10–11px 且归 `--text-decor`。报表 Y/X 轴刻度从 9px 提到 11px 并换成 `--text-3`。
- **sparkline**：1.4px@50% → 2px@65%，不再是看不见的装饰。
- **图表区分度**：报表「估算成本线」从同色钢蓝改为中性灰 + 虚线；主线加粗到 2.2px。
- **登录页品牌连续性**：提交按钮从纯黑 `#0A0D14` 改为 `var(--accent-deep) + var(--on-accent)`，输入框焦点、链接、标题强调字、粒子与光锥全部跟随主题强调色。
- **动效收敛**：入场 580ms → **240ms**、递进 60ms → 30ms、交互反馈 ≤160ms、页间转场 190ms → 150ms、转场幕兜底 1.2s → 600ms；低端设备（≤4 核）关闭指针柔光。保留 `prefers-reduced-motion` 兜底。
- **空态插图区**：`st-ico` 从 42px 扩到 52px 并加浅底色，为后续放等距线稿留出位置。

### 6. 主题切换器

`motion.js` 的 `setupTheme()` 动态注入右下角胶囊，4 个色点，写 `localStorage('qd-theme')`，并广播 `qd-theme-change`；登录页粒子引擎监听该事件重建 sprite。
`<head>` 里的引导脚本在 CSS 之前读取偏好设置 `data-theme`，避免换肤闪烁。

## 五、v0.8 补完（2026-11-11 晚）

v0.7 留下的四件「没做」+ 两处顺手的修正，这一版做完了。**没有动 v0.7 的任何配色与结构**，只加不改。

### 1. 单据详情页（新文件 `单据详情.html`）

- **三级面包屑**：轻单 / 单据 / A-0024，从列表点单据号直接进（列表页的单据号现在是链接）

「打印客户联」按钮直接 `window.print()`；预览文件 `预览/v08-客户联-A4.pdf`（Edge headless 实测导出）。

### 3. 等距空态插图

`motion.js` 里新增 `ART` 与 `setupArt()`：页面里的 `.st-ico` **留空即可**，JS 按上下文（`.st-error` 的祖先）自动补「纸堆 + 虚线空位 + 加号」或「撕开的纸 + 感叹号」，96px，跟随主题强调色。
`.st-ico` 从「虚线圈 + 18px 小图标」改成 96px 无底色容器（`tokens.css`）。
**只在这一个地方画**：五个老页面不用逐个改，插图自动出现。

### 4. 折线图按数据生成

新增 `setupChartPath()`：读 `svg.chart` 的 `data-points`，主线直接用 `x/y`，估算线由 `est` 金额反算 y（`y=260-(V-8000)/1000×30`）。手写死的两条 `d` 不再需要同步维护。
