## 二、v0.8 → v0.9 必须改的结构

1. **侧栏**：4 项 → **8 个域 / 22 项**，分组名与 `NAV_DOMAINS` 一致（公共 / 单据与结算 / 冲正 / 主数据 / 库存 / 组织 / 报表 / 系统），顺序也一样。
2. **单据**：`单据.html` 的一张混排表 → A / B / E / N / C 五个独立页（列表 + 表单 + 行明细），另加「冲正」页做 R / S / I 三分栏。
3. **库存**：1 页 → 数量 / 流水 / 盘点 3 页。
4. **登录页**：「获取验证码」+ 60 秒倒计时；说明文案与 `LoginPage.tsx` 对齐。
5. **工作台**：三块 KPI + 20 个入口卡片，按权限过滤（设计稿只画状态，权限判断归业务）。
6. **字段名**：全部以 `docs/api/openapi.yaml` 为准，中文名不一致的要么改设计稿，要么单独开 issue 提口径变更。
7. **保持不变**：`tokens.css`（四套主题）、`components.css`、`motion.js`、动效与配色体系、`docs/ui/design-tokens.md`。
